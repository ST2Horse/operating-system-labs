# Task 8: 内存管理模拟实验

本实验实现“基于杂凑技术的反置页表方法页式内存管理”的模拟。

## 功能

1. 选择内存物理空间大小：256 MB 或 512 MB。
2. 选择页框大小：1 KB、2 KB 或 4 KB。
3. 计算并显示反置页表项数和表占用空间。
4. 随机产生多个进程的 `(进程号, 进程逻辑空间大小)` 二元组。
5. 按 `Hash(pid, p) = pid * 页框大小 + p` 计算初始表项位置，采用顺序探测解决冲突。
6. 显示非空反置页表项：表项序号、进程号、逻辑页号、冲突次数、空闲/占用标志。
7. 随机选择一个进程和一个 16 位逻辑地址，显示逻辑页号、页内偏移、页框号和实际物理地址。

## 编译

```bash
make
```

## 运行

```bash
./memory_lab
```

## 清理

```bash
make clean
```
