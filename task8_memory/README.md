# Task 8: 内存管理模拟实验

本实验实现操作系统内存管理相关算法的控制台模拟。

## 功能

1. 静态等长分区分配方法：
   - 字位映象图
   - 空闲页面表
   - 空闲页面链
2. 动态异长分区分配方法：
   - 最先适应算法
   - 下次适应算法
   - 最佳适应算法
   - 最坏适应算法
3. 反置页表方法页式内存管理：
   - 可选择内存物理空间大小：256 MB 或 512 MB
   - 可选择页框大小：1 KB、2 KB 或 4 KB
   - 计算反置页表项数和表占用空间
   - 随机生成多个进程二元组
   - 使用 `Hash(pid, p) = pid * 页框大小 + p`
   - 采用顺序探测处理冲突
   - 随机生成 16 位逻辑地址并转换为物理地址

## 编译

```bash
make
```

## 运行

```bash
./memory_lab
```

程序启动后通过菜单选择实验模块。

## 清理

```bash
make clean
```
